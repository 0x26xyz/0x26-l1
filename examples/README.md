# `&` chain examples

Runnable example applications built on top of the published SDKs. These are
fork-and-modify starting points, not production trading systems.

| Path                          | Language | What it shows                                                                       |
| ----------------------------- | -------- | ----------------------------------------------------------------------------------- |
| [`python/llm-trader/`](python/llm-trader) | Python   | LLM-driven directional trading agent on a single market, powered by OpenRouter      |

Each example has its own `README.md` with install, configure, and run-through
instructions.
